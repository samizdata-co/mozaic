Linked sources: `<Source sources={[{ label, href }, …]} />` lists sources with optional links, joined with "; ", with the plural label for more than one. Links open in a new tab and are plain text in print. Every recipe's `source` prop takes the same list as well as plain text. New projects' AGENTS.md asks for linked sources.
