Arrow plots: an `Arrows` mark (one arrow per row from a start to an end value; arrows shorter than their head show the head alone) and two recipes, `ArrowChart` (arrow plot with end values beside the arrowheads, the two dates labelled above the first arrow, and dots for rows with only one value) and `BarDotChart` (bars for the latest value, a dot for an earlier one, and the value and change at the right). Both can be ejected with `mozaic eject`.
