# Data

- `moldova-adm1.topo.json`: Moldova first-level administrative units (37), from
  [geoBoundaries](https://www.geoboundaries.org) gbOpen MDA ADM1 (simplified,
  commit 9469f09). Original source: UNHCR, OCHA FISS via HDX. Licence: CC BY 3.0 IGO.
  Converted with mapshaper (`quantization=100000`; fields renamed to `name`, `iso`).

All values in the test charts are synthetic (seeded random), for testing only.
