# Working with AI

Most mozaic charts are expected to be written by AI agents. The library is designed for that: explicit components, typed props, no hidden behaviour, and a complete example for every common chart.

## What agents get

- **`AGENTS.md`** in the library and in every analysis project: the layout, conventions and checks.
- **A Claude Code skill** (`.claude/skills/mozaic-chart/SKILL.md`) in every analysis project, with a step-by-step procedure for building a chart.
- **[`llms.txt`](../../llms.txt)**: these docs, the full API reference and every gallery example's source in one plain-text file.
- **The gallery**: twenty complete chart files to copy from.
- **Typed props with JSDoc**: editors and models see what each prop does.

## Prompting

Good prompts name the data file, the story and the audience:

> Add a chart to src/charts/turnout/ from data/processed/turnout.csv showing how turnout changed between 2019 and 2024 by region. The point is that only the south fell. Use the slope chart from the gallery as a starting point.

## Checking an agent's work

- `pnpm check` and `pnpm build` pass.
- Look at the preview at 320 px and 1000 px, in every language, and in print.
- Labels do not overlap or get cut off; tooltips work; the title states the finding.
- Every string is translated, `alt` is written, sources are cited.
